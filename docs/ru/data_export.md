# Экспорт данных

Раздел **Экспорт данных** позволяет выгружать данные из системы Triel во внешние базы данных. Экспорт можно выполнять вручную или по расписанию, при этом строки исходной таблицы переносятся в таблицу целевой базы данных согласно заданному сопоставлению колонок.

Раздел состоит из двух вкладок:
* **Задачи экспорта** — настройка и запуск задач выгрузки данных.
* **Подключения** — настройка подключений к целевым базам данных.

Перед созданием задачи экспорта необходимо создать хотя бы одно подключение к базе данных.

## Подключения

Вкладка **Подключения** содержит список настроенных подключений к внешним базам данных. Для каждого подключения отображаются: название, тип БД, хост, порт, имя базы данных и имя пользователя.

Поддерживаемые типы баз данных:
* PostgreSQL
* MySQL
* MS SQL Server
* Oracle

### Создание и редактирование подключения
При создании или редактировании подключения нужно заполнить поля:
* `Название` — произвольное имя подключения для удобной идентификации.
* `Тип БД` — тип целевой базы данных (см. список выше).
* `Хост` — адрес сервера базы данных (имя хоста или IP-адрес).
* `Порт` — порт сервера базы данных (число от 1 до 65535).
* `База данных` — имя базы данных.
* `Пользователь` — имя пользователя для подключения.
* `Пароль` — пароль пользователя. При редактировании оставьте поле пустым, чтобы сохранить текущий пароль.
* `Дополнительные параметры JDBC` — необязательное поле для указания дополнительных параметров строки подключения JDBC (см. ниже).

> Все поля, кроме `Дополнительные параметры JDBC`, обязательны для заполнения. В целях безопасности пароль никогда не отображается после сохранения.

#### Дополнительные параметры JDBC
Значение этого поля добавляется сервером к строке подключения JDBC без изменений. Разделитель между адресом базы данных и параметрами подставляется автоматически в зависимости от типа БД, поэтому указывать его в начале поля **не нужно**:
* для PostgreSQL, MySQL и Oracle используется разделитель `?`, несколько параметров соединяются символом `&`;
* для MS SQL Server используется разделитель `;`, несколько параметров также соединяются символом `;`.

Примеры значений поля и итоговых строк подключения:

* **PostgreSQL** — параметры: `sslmode=require`

  ```
  jdbc:postgresql://10.0.0.5:5432/warehouse?sslmode=require
  ```

* **MySQL** — параметры: `useSSL=false&allowPublicKeyRetrieval=true`

  ```
  jdbc:mysql://10.0.0.5:3306/warehouse?useSSL=false&allowPublicKeyRetrieval=true
  ```

* **MS SQL Server** — параметры: `encrypt=false;trustServerCertificate=true`

  ```
  jdbc:sqlserver://10.0.0.5:1433;databaseName=warehouse;encrypt=false;trustServerCertificate=true
  ```

* **Oracle** — параметры: `oracle.net.CONNECT_TIMEOUT=5000`

  ```
  jdbc:oracle:thin:@//10.0.0.5:1521/warehouse?oracle.net.CONNECT_TIMEOUT=5000
  ```

> Набор допустимых параметров определяется драйвером соответствующей базы данных. Максимальная длина поля — 1024 символа.

### Проверка подключения
В контекстном меню подключения доступно действие **Проверить подключение**. Оно выполняет тестовое соединение с базой данных и сообщает, успешно ли установлено подключение. Рекомендуется проверять подключение после его создания и перед использованием в задачах экспорта.

### Удаление подключения
Подключение можно удалить через контекстное меню. Если подключение используется хотя бы одной задачей экспорта, удалить его не получится — сначала удалите или измените связанные задачи.

## Задачи экспорта

Вкладка **Задачи экспорта** содержит список настроенных задач выгрузки. Для каждой задачи отображаются: название, используемое подключение, исходная таблица, целевая таблица, расписание, статус активности и дата последнего изменения.

### Создание и редактирование задачи
При создании или редактировании задачи нужно заполнить поля:
* `Название` — произвольное имя задачи.
* `Подключение` — подключение к целевой базе данных (из списка созданных ранее).
* `Исходная таблица` — таблица системы Triel, из которой выгружаются данные.
* `Целевая таблица` — таблица целевой базы данных, в которую записываются данные. Список таблиц загружается автоматически после выбора подключения.
* `Расписание` — периодичность автоматического запуска задачи (см. ниже).
* `Активна` — флажок включения/выключения задачи. Отключённая задача не запускается по расписанию.

#### Сопоставление колонок
Для задачи необходимо задать сопоставление колонок — какая колонка исходной таблицы в какую колонку целевой таблицы переносится.
* Чтобы добавить сопоставление, нажмите **Добавить колонку** и выберите исходную и целевую колонки.
* Должно быть задано хотя бы одно сопоставление.
* Одна и та же исходная или целевая колонка может использоваться только один раз.
* Если типы исходной и целевой колонок несовместимы, рядом с сопоставлением отображается предупреждение.

### Расписание
Расписание определяет, как часто задача запускается автоматически:
* `Вручную` — задача запускается только вручную.
* `Каждую минуту`
* `Каждые 5 минут`
* `Каждые 10 минут`
* `Каждый час`
* `Каждые 12 часов`
* `Каждые 24 часа`

> Экспорт является инкрементальным: при каждом запуске выгружаются только новые строки, добавленные после предыдущего запуска. Система запоминает идентификатор последней выгруженной строки.

### Запуск задачи вручную
В контекстном меню задачи доступно действие **Запустить сейчас**. Оно немедленно запускает выгрузку данных независимо от расписания (требуется подтверждение).

### История запусков
Действие **История запусков** открывает журнал прошлых выполнений задачи. Для каждого запуска отображаются:
* `Статус` — успешно (`SUCCESS`) или с ошибкой (`FAILURE`).
* `Начало` — время начала выполнения.
* `Конец` — время завершения выполнения.
* `Строк экспортировано` — количество выгруженных строк.
* `Ошибка` — текст ошибки, если запуск завершился неудачно.

### Удаление задачи
Задачу можно удалить через контекстное меню (требуется подтверждение).
